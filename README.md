# 圣诞树之夜 · Christmas Room

一个三四个人同时在线玩的圣诞主题网页房间游戏，单个 Node 进程即可运行（静态页 + WebSocket 实时同步都在同一个服务里）。

## 玩法

进站先捏像素小人（肤色 / 头发 / 上衣 / 裤子 / 鞋子 / 发型），填名字和密码注册；下次用同一个名字 + 密码登录，角色（含糖果数）会回来。

| 操作 | 键位 |
| --- | --- |
| 走路 | `W` `A` `S` `D`，`Shift` 加速 |
| 捡东西 / 互动 | `F`（走到物品上会自动捡起） |
| 戴帽子 / 面具 / 披风 | `1` `2` `3` |
| 投掷 | 鼠标点画面 / `Q` |
| 挥拳 | 手里没东西时点画面 / `J` |
| 骑到别人背上 | `E`（再按一次下来） |
| 喝热可可 | `H` |
| 跳舞 | `G` |
| 聊天 | `Enter` |

房间里有一棵五层圣诞树、礼物盒（钻进去隐身 3 秒）、热可可锅（舀一杯回血）。每 90 秒来一次「礼物风暴」，地板会喷出装扮和糖果。

## 本机跑

```bash
npm install --omit=dev
PORT=3000 node server.js
```

打开 http://localhost:3000

## 部署到 Render（免费）

1. 把本目录所有文件上传到一个新的 GitHub 仓库（公开即可）
2. 打开 https://dashboard.render.com ，用 GitHub 账号登录
3. 点 `New +` → `Blueprint`，选中这个仓库，Render 会读到 `render.yaml` 自动建服务
4. 等构建完成，拿到 `https://xxxx.onrender.com` 这样的地址，直接发给朋友玩

说明：页面会自动识别所在域名——在 Render 等自建域名下走同域直连 WebSocket（延迟最低），在豆包静态空间里才退回公共 MQTT 中转。

免费实例闲置 15 分钟后会休眠，下次有人打开会自动唤醒（首次打开可能要等几十秒）。账号数据写在 `data/` 目录，属于实例本地磁盘，重新部署或实例重建会清空。
